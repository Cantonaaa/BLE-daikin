# BLE-Daikin

通过 ESP32-S3 的 BLE 控制大金 VRV 中央空调多台室内机的开关。

## 功能

### 核心功能（所有版本）

- ✅ **AP 热点配网** — 首次上电自动开热点 "BLE-Daikin"，无密码
- ✅ **DNS 劫持** — 连上热点后手机自动弹出配网页，无需手动输入 IP
- ✅ **WiFi 配网** — 页面扫描周围 WiFi、选择网络、输入密码、保存重启
- ✅ **BLE 扫描** — 手动选择室外机进行连接
- ✅ **GATT 服务自动发现** — 不依赖固定 handle，自适应不同设备
- ✅ **多台室内机独立开关** — 动态发现，每台分机单独控制
- ✅ **断线自动重连** — 扫描到已保存设备时自动连接
- ✅ **分机改名** — 点击名称即可改名，存入 NVS 重启不丢失
- ✅ **定时开关** — 每台分机独立设置 ON/OFF 时间，到点自动执行
- ✅ **Web 控制界面** — 手机/电脑浏览器访问，页面自动刷新
- ✅ **页面显示 IP 地址** — 无需查路由器
- ✅ **WiFi 连接失败回退** — 5 次失败后自动开热点，可重新配网
- ✅ **SNTP 时间同步** — NTP 获取北京时间，中国时区 UTC+8

### 语音功能（语音版额外支持）

- 🎤 **离线语音控制** — 说"你好小智"唤醒，6 秒内说指令，全程不联网
- 🎤 **分机名动态同步** — Web 改名后自动注册为语音命令，改名即能喊
- 🎤 **中文命令词** — 支持"打开空调""关闭空调""打开[分机名]""关掉[分机名]"

## 硬件要求

### 通用

- **ESP32-S3**（推荐 N16R8：16MB Flash / 8MB Octal PSRAM）
- **USB 供电**（5V/500mA 以上）
- 需要在大金室外机 BLE 信号范围内（约 10-20 米，视墙体衰减）

### 硬件适配

本固件默认配置为 **ESP32-S3 N16R8**。其他型号需修改 `ESP/sdkconfig.defaults`：

| 型号 | Flash | PSRAM | 修改方式 |
|---|---|---|---|
| **N16R8** | 16MB | 8MB Octal | ✅ 当前默认配置 |
| **N8R2** | 8MB | 2MB Quad | `CONFIG_ESPTOOLPY_FLASHSIZE_8MB=y` → `# CONFIG_SPIRAM_MODE_OCT` → `CONFIG_SPIRAM_MODE_QUAD=y` |
| **N4R2** | 4MB | 2MB Quad | 同上，`FLASHSIZE_4MB` |
| **无 PSRAM** | 任意 | 无 | 删除所有 `CONFIG_SPIRAM*` 行 |

### INMP441 麦克风接线（语音版）

| INMP441 引脚 | ESP32-S3 GPIO |
|---|---|
| VDD | 3.3V |
| GND | GND |
| SCK（时钟） | GPIO 6 |
| WS（声道选择） | GPIO 7 |
| SD（数据） | GPIO 5 |
| L/R | GND（左声道） |

## 快速开始

### 下载固件

从 [Releases](https://github.com/Cantonaaa/BLE-daikin/releases) 下载对应的 `.bin` 文件，无需编译。

### 烧录

```bash
# 安装烧录工具
pip install esptool

# 擦除旧配置（首次烧录或换路由器时执行一次）
esptool.py --chip esp32s3 --port <PORT> erase_flash

# 烧录固件
esptool.py --chip esp32s3 --port <PORT> write_flash 0x0 BLE-Daikin-N16R8-all.bin
```

将 `<PORT>` 替换为实际端口：`COM3`（Windows） `/dev/ttyACM0`（Linux） `/dev/cu.usbserial-xxxx`（macOS）。

### 编译（可选）

```bash
cd ESP
idf.py build
```

编译语音版需额外下载 ESP-SR 组件：
```bash
cd ESP
git clone --depth 1 https://github.com/espressif/esp-sr.git components/esp-sr
idf.py set-target esp32s3
idf.py build
```

编译后合并为单个文件：
```bash
esptool.py --chip esp32s3 merge_bin --output BLE-Daikin-all.bin \
  0x0 build/bootloader/bootloader.bin \
  0x8000 build/partition_table/partition-table.bin \
  0x10000 build/BLE-Daikin.bin
```

## 使用指南

### 首次配网

| 步骤 | 操作 |
|---|---|
| ① 上电 | ESP32 通电，自动开热点 **"BLE-Daikin"**（无密码） |
| ② 连热点 | 手机 WiFi 列表中找到并连接该热点 |
| ③ 自动弹窗 | 手机自动弹出配网页（DNS 劫持），或浏览器打开 `http://192.168.4.1` |
| ④ 扫描 WiFi | 点击"扫描 WiFi"，选择你家网络，输入密码 |
| ⑤ 保存重启 | 点击"连接"，ESP32 保存凭证并重启 |
| ⑥ 自动连接 | 重启后自动连上你家 WiFi，页面顶部显示 IP 地址 |

### 连接空调

| 步骤 | 操作 |
|---|---|
| ① 打开网页 | 浏览器访问 `http://<ESP32-IP>`（IP 在页面顶部显示） |
| ② 扫描 BLE | 点击"扫描蓝牙设备"，等待 5 秒 |
| ③ 选择设备 | 在设备列表中找到你的大金室外机，点击"连接" |
| ④ 自动发现 | 连接后自动发现分机，页面显示各室内机的开关状态 |

### 日常控制

| 操作 | 方法 |
|---|---|
| **开关分机** | 点击分机卡片上的 **开/关** 按钮 |
| **改名** | 点击分机名称，输入新名字（如"客厅""主卧"） |
| **设定时** | 在分机卡片下方设置 ON/OFF 时间（HH:MM 格式） |
| **查看 IP** | 页面顶部显示当前 IP 地址 |

## 语音指令

说 **"你好小智"** 唤醒 → 6 秒内说出指令：

| 指令 | 效果 |
|---|---|
| **"打开空调"** | 所有已发现的分机开机 |
| **"关闭空调"** | 所有已发现的分机关机 |
| **"打开[分机名]"** | 指定分机开机，如"打开客厅" |
| **"关掉[分机名]"** | 指定分机关机，如"关掉卧室" |

分机名以 Web 页面显示的为准。例如改名为"客厅""卧室""书房"后：

> "打开客厅" → 客厅开机  
> "关掉卧室" → 卧室关机  
> "关闭空调" → 全部关机

### 分组控制（同音/同字自动归组）

- 多个分机**同名**（如都叫"客厅"）或**同音**（如"客厅"和"客听"），会自动归为一组
- 说一次指令，**组内所有分机同时开关**

> "打开客厅" → 所有叫"客厅"或同音（客听）的分机一起开机

- 改名请使用**中文**（英文名无法被语音识别，会被拒绝）
- 未改名的分机使用默认名"空调1""空调2"…（按发现顺序编号）
- 名称中的**阿拉伯数字**也能识别（如"空调2"同"空调二"），数字相同的名字归为一组
- 语音中数字按**逐位**读（如"空调10"要说"空调一零"，不是"空调十"）

### 配网流程

```
上电 → NVS 有 WiFi 凭证？
  ├── 是 → STA 模式 → 连接你家 WiFi → 获取 IP → SNTP 时间同步
  │                  失败 5 次 → 回退 AP 模式
  │
  └── 否 → APSTA 模式
           ├── 开热点 "BLE-Daikin"
           ├── DNS 劫持：所有域名 → 192.168.4.1（配网页自动弹出）
           └── 等待用户配网
                ├── 用户扫描 WiFi → 列表显示
                ├── 用户选网络输密码 → 保存到 NVS → 重启
                └── 重启后走 STA 分支
```

### BLE 控制流程

```
上电 → NimBLE 初始化
  ├── NVS 有保存的室外机地址？
  │   ├── 是 → 扫描发现该设备 → 自动连接
  │   └── 否 → 等待用户在 Web 页面手动选择
  │
  └── 连接成功 → GATT 服务发现
       ├── 扫描所有服务/特征值
       ├── 找到可写的特征值 → 保存 handle（后续发指令用）
       ├── 找到 0x6528（分机状态）→ 订阅通知
       └── 标记 connected = true

连接后 → 室外机每 20 秒推送通知
  ├── 解析通知数据 → 提取分机 ID 和 ON/OFF 状态
  ├── 添加到 units[] 数组（动态发现）
  └── Web 页面下次刷新自动显示

用户点开关 → 构造 24 字节指令包
  ├── [4f=开/4e=关] + [分机 ID] + [校验和]
  ├── 写入特征值（Write Request）
  └── 室外机执行 → 下次通知更新状态
```

### 语音识别流程（语音版）

```
I2S 麦克风 → 16kHz 16bit 音频
  → AFE 前端处理（降噪、回声消除）
  → WakeNet9 唤醒词检测
  → MultiNet6 命令识别
  → 回调执行空调控制
```

## 技术细节

| 模块 | 技术栈 | 说明 |
|---|---|---|
| **BLE 协议栈** | Apache NimBLE | ESP-IDF v5.4 内置，轻量级 BLE 主机协议栈 |
| **BLE 角色** | GATT Client | 连接室外机、写特征值、订阅通知 |
| **控制指令** | 24 字节 Write Request | 格式从抓包逆向，checksum = sum bytes[2..22] |
| **分机识别** | Handle `0x6528` 通知 | 每 20 秒推送，`data[9]`=ID，`data[15..16]`=状态 |
| **WiFi 配网** | APSTA 双模式 | 无凭证时开热点，有凭证时连 STA |
| **DNS 劫持** | UDP 53 端口 | 所有域名 → 192.168.4.1，自动弹出配网页 |
| **Web 服务器** | ESP HTTP Server | 内嵌 HTML + CSS + JavaScript，5 秒自动刷新 |
| **数据持久化** | NVS Flash | WiFi 凭证、BLE 地址、分机名、定时设置 |
| **时间同步** | SNTP + NTP | CST-8 北京时区，用于定时功能 |
| **语音引擎**（语音版） | ESP-SR v2.4 | WakeNet9 唤醒 + MultiNet6 命令识别 |
| **麦克风**（语音版） | I2S + INMP441 | 16kHz, 16bit, 单声道 |
